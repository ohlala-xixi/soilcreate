# SoilCreate SoilCreate-Style Product Import Rule

This internal rule was moved out of `docs/public/tools/` so it is not published as a public crawlable file.

Use it when importing Rasber-style product pages into SoilCreate while keeping SoilCreate brand colors, enquiry forms, downloads, related products, related case studies, related solutions, and catalog navigation.

## Core Rules

- Keep SoilCreate header and footer.
- Keep SoilCreate theme color system, especially `#D96B3A` for the main accent.
- Do not copy Rasber blue as a brand color.
- Remove Rasber CTA blocks.
- Keep SoilCreate inquiry form and Formspree workflow.
- Keep downloads and catalog buttons.
- Keep related products, related case studies, and related solutions.
- Related case studies and related solutions should show no more than four cards each.
- Use real product images where available.
- Run `npm run build` after changes.
