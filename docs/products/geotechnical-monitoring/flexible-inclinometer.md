The SoilCreate Shape Displacement Array is a segmented 3D deformation monitoring system for large deformation and complex installation conditions. It is also known as a flexible inclinometer or SAA. Rigid sensing segments alternate with flexible joints, allowing the array to follow curved layouts while reconstructing the full deformation shape from linked segment vectors.

The same product can be installed vertically for borehole inclinometry, horizontally for settlement monitoring, or in a ring layout for tunnel convergence. Because the array is segmented, it can be assembled to match project length, recovered at project completion, inspected, and redeployed on a later project.

For configuration, share installation direction, total monitoring length, preferred segment length, expected deformation range, water pressure, acquisition frequency, communication method, and whether the project requires recovery and reuse after completion.
