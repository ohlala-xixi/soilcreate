## Definition

An **inclinometer selection guide** helps a project team decide whether a manual sliding inclinometer, an in-place inclinometer, or a flexible displacement array is the right way to measure subsurface deformation. The answer depends on the expected movement mechanism, the depth and shape of the deformation zone, the required reading frequency, and whether field crews can access the borehole safely throughout the project.

## Start With the Risk Mechanism

The first selection question is not "Which sensor is best?" It is "What movement would change the engineering decision?"

For a deep excavation, the concern may be lateral wall movement, basal instability, or movement linked with groundwater and strut load. For a slope or landslide, the key question may be whether a slip zone is developing at depth. For a dam or embankment, the target may be internal deformation that cannot be seen from the surface. For a tunnel, the monitoring team may need to understand convergence, surrounding ground movement, or deformation around a shaft or portal.

Once the movement mechanism is clear, the instrument choice becomes more practical. The team can decide whether it needs a manual borehole profile, an installed sensor-chain profile, or a segmented shape profile reconstructed from array measurements.

| Option | Best Fit | Main Limit | Selection Check |
| --- | --- | --- | --- |
| Manual sliding inclinometer | Periodic profiles in multiple accessible boreholes | Requires trained field work and repeatable access | Can crews read the casing on schedule and control A0/A180 repeatability? |

| Automated traversing inclinometer | Repeated automatic profiles in existing casing | More moving parts and higher system complexity | Is the casing condition, power, lifting route, and maintenance access reliable? |

## Match Reading Frequency to Site Risk

Manual readings can be suitable when movement is slow, the project has regular access, and the monitoring plan only needs periodic profile checks. They are also useful for verification surveys because one instrument can serve multiple boreholes.

Automated in-place monitoring fits projects where the risk changes quickly or where field access is limited. It is often selected when the team needs frequent readings at known critical depths, such as a retaining wall zone, slope slip zone, dam core, or tunnel-adjacent borehole.

Flexible arrays fit projects where the deformation shape matters. Instead of checking only a few sparse reading points, the array reconstructs a shape profile from its installed segments. That can be useful where the deformation zone is broad, uncertain, or expected to migrate.

## Check Borehole Depth, Access, and Installation Constraints

The planned borehole depth should cover the expected deformation zone and reach stable reference ground where required by the monitoring design. If the borehole is too shallow, even a high-quality instrument can miss the movement mechanism.

Access is just as important. A manual sliding inclinometer needs a casing top that can be reached safely and consistently. An in-place inclinometer needs protected cable routing, a data logger location, power, and communication. A flexible array needs careful planning for segment length, protection, anchoring, and recovery if the project expects reuse.

Existing casing should be checked before the instrument is selected. Damaged grooves, obstruction, large deviation, water, debris, or casing movement can affect the usable options.

<h2 class="sc-article-orange-heading">Selection Workflow</h2>

1. Define the deformation mechanism and the decision the data must support.
2. Confirm the monitoring depth, expected movement zone, and required reference condition.
3. Decide whether the project needs periodic profiles, installed sensor-chain automation, or segmented shape data.
4. Check field access, power, communication, cable protection, and maintenance limits.
5. Confirm data format, alarm workflow, reporting frequency, and long-term data traceability.

## Data Quality Should Be Part of Selection

Instrument selection is not finished when the sensor type is chosen. The team also needs to know how the baseline will be established, how repeat readings will be checked, and how suspicious values will be reviewed.

For manual readings, repeatability depends on casing condition, probe handling, reading interval, direction control, and field notes. For automated systems, quality depends on sensor depth, cable protection, logger stability, time synchronization, data gap handling, and alarm review.

The practical question is simple: when a reading changes, can the team explain whether it is likely to be ground movement, construction activity, installation influence, or instrument/data noise?

## Common Selection Mistakes

### Choosing automation only because it looks advanced

Automation improves frequency and response time, but it does not fix a weak monitoring layout. If the critical depth is unknown or the borehole is poorly placed, automatic readings may only produce faster uncertainty.

### Using manual surveys where access will disappear

Manual sliding inclinometers are useful when trained crews can return to the casing. If excavation staging, traffic, water, security, or weather will block access, the monitoring plan should consider an automated option earlier.

### Ignoring the shape of deformation

Some projects need automated readings along selected installed sensor positions. Others need to see how deformation is distributed along a borehole or structure. Treating both cases the same can lead to over-specified or under-informative monitoring.

### Comparing instruments without comparing the workflow

A practical system includes installation method, baseline procedure, data collection, quality checks, alarm logic, reporting, spare parts, and field support. The cheapest sensor is not always the lowest-risk choice.

## FAQ

### 1. How do you choose the right inclinometer system?

Start from the movement mechanism, expected monitoring depth, reading frequency, access constraints, and required data output, then match those needs to manual, in-place, flexible, or combined inclinometer workflows.

### 2. When should a project consider a flexible displacement array?

A flexible displacement array is useful when the project needs a segmented shape profile or when deformation may be distributed along a borehole, embankment, slope, retaining structure, or tunnel-related alignment.

### 3. Is reading frequency enough to choose the right inclinometer?

No. Frequency matters, but the team should also check the deformation mechanism, monitoring depth, access, installation protection, data workflow, and how the readings will support field decisions.

### 4. Can one project use more than one inclinometer type?

Yes. A project may use manual surveys for verification, in-place sensor chains for critical automated readings, and flexible arrays where a segmented profile is needed.

### 5. What information should be prepared before requesting a recommendation?

Prepare the project type, expected deformation mechanism, borehole depth, access limits, reading frequency, alarm needs, data export format, and any existing casing condition.
