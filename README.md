# SoilCreate Catalog

Static VitePress site scaffold for the SoilCreate brand catalog.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run generate:specs`

## Notes

- Replace the Formspree endpoint in `docs/.vitepress/theme/components/InquiryForm.vue`.
- Replace the contact placeholders in `docs/contact.md`.
- Generated PDF spec sheets are written to `docs/public/specs/`.
